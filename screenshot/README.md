# Linksy for Android: screenshots

For the website and store listings. Taken on a Pixel-size emulator (1080×2400) in the
app's demo mode (`--dart-define=LINKSY_DEMO=true`, made-up devices), with a clean status
bar. Version 0.1.9+ (device pictures).

| File | What it shows |
|---|---|
| `home.png`, `home-dark.png` | Home: paired devices (one with a picture), a device nearby to pair |
| `device.png`, `device-dark.png` | A computer’s page with its picture as the banner, fading into a shadow under the name |
| `device-no-picture.png`, `device-no-picture-dark.png` | A computer's page without a picture: the dark blue grid banner fading into the same shadow |
| `device-timeline.png` | The same page scrolled: actions, See its screen, photo backup, and the timeline |
| `incoming-files.png` | "Studio Desktop is sending you 3 files", Accept / Decline |
| `remote.png` | Remote: the phone as touchpad and keyboard |
| `remote-slides.png` | Remote: presentation mode (Next / Back, volume keys) |
| `settings.png` | Settings: this phone, saving to Downloads, background, calls |
| `terminal-entry.png` | A computer's page with the Terminal card (shown only for computers announcing `terminal`) |
| `terminal-start.png` | Terminal: start screen, "A shell on Studio Desktop", New terminal |
| `terminal-wrong-code.png` | The terminal code prompt after a wrong code: "Wrong code, 4 tries left" |
| `terminal-live.png` | A live terminal with colours, and the key bar above the keyboard |
| `terminal-tab-title.png` | The tab and header following the shell's window title ("top — ~") |
| `terminal-detached.png` | Detached: still running on the computer, Reattach |
| `terminal-close.png` | The Close button in the header and the × on each tab |
| `terminal-close-confirm.png` | "Close this terminal?" with Keep running / Close |
| `terminal-real-shell.png` | A real login shell (zsh on a Mac test computer) through the 0.7 core |
| `terminal-still-running.png` | Start screen listing a terminal still running on the computer, Reattach |
| `terminal-exit.png` | After typing `exit`: the tab closed, "“Terminal” ended on …" |
| `device-status.png` | A computer's page: name, its kind, and a small "Same Wi-Fi" under it |

The device picture is a flat illustration in the brand colors, made for these shots.
